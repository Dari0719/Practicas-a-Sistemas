# Practicas-a-Sistemas

## Descripción

Proyecto grupal para el desarrollo de una aplicación de juego de lógica y cálculo, inspirada en la dinámica del juego **All Ten**.

La aplicación será desarrollada utilizando **Java, JavaFX y una base de datos relacional**, siguiendo el patrón arquitectónico **MVC (Model-View-Controller)**.

El proyecto busca ofrecer una experiencia de juego clara e intuitiva, aplicando principios y técnicas de **UX (User Experience)** durante las diferentes etapas de diseño y desarrollo.

> **Nota:** Las reglas definitivas, el nombre del juego y algunas características de la aplicación serán definidos y refinados durante el desarrollo del proyecto.

---

## Objetivo del proyecto

Desarrollar una aplicación de escritorio basada en un juego de lógica y cálculo, aplicando buenas prácticas de desarrollo de software, arquitectura MVC, gestión de bases de datos, control de versiones y principios de experiencia de usuario.

El desarrollo se realizará de manera iterativa mediante la metodología **Scrum**, organizando el trabajo en historias de usuario, tareas y Sprints.

## Arquitectura

La aplicación seguirá el patrón arquitectónico **MVC (Model-View-Controller)**:

* **Model:** Contendrá la lógica de negocio, los datos y las entidades del sistema.
* **View:** Representará la interfaz gráfica desarrollada con JavaFX.
* **Controller:** Gestionará la interacción entre la interfaz y la lógica de la aplicación.

La estructura definitiva de los componentes se documentará a medida que avance el desarrollo.

## Experiencia de usuario (UX)

El desarrollo de la aplicación tendrá en cuenta principios de **UX** para diseñar una experiencia de juego clara, sencilla e intuitiva.
